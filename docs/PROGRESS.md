## Phase 1: Runnable foundation (implemented, tested)

Completed behavior
- Repository layout: `api/` (FastAPI, migrations, tests), `web/` (React/Vite/TS), `fixtures/`,
  `scripts/`, `docs/`, `.github/workflows/`, `compose.yaml`.
- Compose stack with separate backend and frontend networks and a persistent `pgdata` volume:
  `db` → `migrate` (one-shot release job) → `api` → `web` (nginx serving the built app).
- Advisory-locked, checksummed, forward-only SQL migration runner with bounded connect retry.
- `/health` (liveness) and `/ready` (PostGIS version and migration state; 503 when not ready),
  request IDs, aggregate request logs without bodies, machine-readable error envelope,
  CORS restricted to configured origins.
- Readiness screen in React that reports ready, degraded (API up, DB down) or unreachable,
  with retry.
- CI: ruff, ruff format, mypy strict, pytest against a PostGIS service container; eslint, tsc,
  vitest, Vite build; clean compose boot plus a Playwright connectivity check.

## Phase 2: Reproducible fixtures and comparison engine (implemented, tested)

Completed behavior (details in [ENGINE.md](ENGINE.md))
- `geodiff.engine`: GeoJSON validation (sampled issues with exact counts and remediation
  guidance), documented ID policy, Karney geodesic distances on WGS84, change detection with
  per-component patches (`geodiff.comparison/1`), and resolution into draft/final exports with
  a `geodiff.report/1` report.
- CLI: `geodiff validate | compare | resolve | generate`.
- Seeded generator for the fictional Cedar Hollow Parks Department (5,000 assets, seed
  20261118), with an independent change manifest and synthetic streets/blocks/parks/paths.
- Hand-authored 13-feature golden pair with expected changes, decisions and expected export.
- Invalid examples, one file per failure code.
- BENCH-0142: move 119.607 m at a 6.3° bearing, plus condition `good` → `damaged`.

Commands and results (2026-11-18)
- `make check-api`: ruff, format and mypy strict clean; **pytest 86 passed**, including:
  - synthetic 5,000 vs manifest: 543/543 components matched, 0 false positives, 0 misses
    (75 additions, 65 deletions, 131 moves, 272 attribute edits; 512 affected assets);
    910/910 sub-threshold motions classified unchanged; 10/10 near-threshold moves of
    2.01–2.05 m detected; move distances within 5 mm of intent;
  - golden comparison and final export equal the hand-authored files exactly;
  - PostGIS geography vs pyproj within 1 mm (BENCH-0142, 89.9° latitude, antimeridian);
  - GeoPandas/GDAL reads the same features; UTM 14N planar distances within 0.1%;
  - export re-import and re-compare yields zero changes.
- `geodiff compare` on the 5,000 pair: 512 assets / 543 components.

## Phase 3: Persistent review API (implemented, tested)

Completed behavior (details in [API.md](API.md))
- Migration `0002_review_schema`: workspaces, datasets (original bytes and SHA-256),
  immutable snapshots, features (unique per snapshot and asset; GIST), comparisons (revision,
  lineage), change_components (GIST on from/to), comparison_assets, decisions (versioned;
  flagged requires a note), review_events (append-only; unique per component version).
- Anonymous workspaces: bearer token, only its SHA-256 stored, 72 h sliding expiry with purge,
  reset and delete; cross-workspace access returns 404.
- Streaming upload limit (413), media-type check (415), duplicate-import dedupe, sampled
  validation, rate limits, capacity limits.
- Comparison runs with lineage; paginated queue; viewport map and baseline queries; evidence
  per asset; atomic versioned decisions; bulk preview with count-confirmed apply; undo by
  revision; history; draft/final export with report.

Commands and results (2026-11-18)
- `make check-api`: **107 passed** (21 new API integration tests against PostGIS 3.5).
  Covered: partial BENCH-0142 decision (attribute accepted, location kept); accepted, rejected
  and pending additions and deletions; cross-workspace denial on 9 endpoints; expiry and
  purge; duplicate import; restart via pool close; stale-tab 409 with atomic rollback; 4
  concurrent identical decisions (1 succeeds, 3 conflict); bulk count mismatch; undo with
  stale revision; final export blocked then equal to the golden file; re-import of the export.
- `scripts/api_walkthrough.py` against compose, then `docker compose restart api db`, then
  `--verify`: decisions persisted; the final export over HTTP equals
  `expected_reviewed.geojson`; workspace deleted.
- `scripts/load_5000.py`: API RSS 57 → 91 MiB; compare 0.60 s; queue 0.04 s; viewport 0.09 s.

Limitations
